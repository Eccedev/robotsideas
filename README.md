# 🤖 RobotsIdeas - Memes y Mente

> **"Humor y mejora personal para las personas no muy cuerdas y las que sí 😉"**

Bienvenido al repositorio oficial de **RobotsIdeas**, un proyecto humano (y algo anómalo) nacido de una descarga cuántica fallida: los **QuBoX**. Este sitio web es el hub central donde el humor absurdo se encuentra con la productividad y la gestión emocional.

---

## 🌌 Sobre el Proyecto

**RobotsIdeas** no es solo una web de memes. Es un ecosistema digital diseñado para:
- 🧠 **Hackear tu mente:** Tips para gestionar el *overthinking*, la autocrítica y el estrés.
- ⏱️ **Productividad Cuántica:** Herramientas para que tu "yo del futuro" no te odie.
- 🎨 **Creatividad Absurda:** A través de los QuBoX (fragmentos robóticos multipersonalidad), exploramos dilemas éticos y situaciones cotidianas con un toque "estrafa-qu-lario".

### Secciones Principales:
- **Los Qubox Cuánticos:** Viñetas interactivas y transparentes.
- **Memes Qlo Descarados:** Humor diario para un *detox* mental necesario.

---

## 🛠️ Especificaciones Técnicas

Este proyecto está construido con un enfoque en **rendimiento, accesibilidad y simplicidad**, utilizando tecnologías nativas para garantizar una carga ultrarrápida.

### Core Stack:
- **HTML5 Semántico:** Estructura optimizada para accesibilidad y SEO.
- **CSS3 Moderno:** 
  - Sistema de **variables CSS** para gestión de temas.
  - Layout basado en **Flexbox** y **CSS Grid**.
  - Diseño **Responsive First**.
- **Vanilla JavaScript (ES6+):** Lógica ligera sin dependencias externas (jQuery-free).

### Características Destacadas:
- 🌓 **Dual Theme System:** Interruptor de modo Claro/Oscuro con persistencia en `localStorage`.
- 🛡️ **Seguridad:** Implementación de **Content Security Policy (CSP)** para mitigar ataques XSS.
- 📱 **PWA Ready:** Configuración de manifiesto y set completo de iconos para instalación en dispositivos móviles.
- ♿ **Accesibilidad (A11y):** Enfoque en navegación por teclado, uso de atributos ARIA y contrastes optimizados.
- 🚀 **Performance:** Cero frameworks pesados, optimización de assets y carga suave.
